# chain_analytics
Jupyter notebook from chain analytics masterclass

This repository contains my Jupyter Notebook from the Chain Analytics Masterclass.  
It covers supply chain analytics concepts and Python-based analysis.  

This project began as part of a Chain Analytics Masterclass, which covered the basics of data cleaning on a single dataset. Building on that foundation, I extended the work into a full end-to-end retail operations analysis across five linked datasets — Orders, Products, Delivery, Returns and Inventory — covering delivery performance, revenue drivers, return patterns, store-level efficiency and stock health.

Objective
•	Validate and merge five raw operational datasets into one clean, analysis-ready table.
•	Build an executive KPI scorecard covering revenue, delivery performance, returns and inventory.
•	Identify delivery bottlenecks, underperforming stores/partners and return drivers.
•	Surface actionable insights for operations and inventory planning.
